# Proyecto Final - Aplicación Móvil Android

## Descripción del proyecto

Este repositorio contiene el desarrollo de una aplicación móvil funcional para Android, creada como proyecto final académico. La aplicación se desarrolla utilizando Android Studio, Kotlin y Jetpack Compose, aplicando principios de Programación Orientada a Objetos, navegación entre pantallas e interfaces modernas.

El proyecto también se gestiona mediante control de versiones con Git y GitHub, permitiendo organizar el trabajo en ramas, registrar avances mediante commits y facilitar la colaboración entre los integrantes del equipo.

## Objetivo general

Desarrollar una aplicación móvil funcional en Android aplicando Programación Orientada a Objetos, navegación e interfaces modernas con Jetpack Compose, gestionando el proyecto mediante control de versiones.

## Tecnologías utilizadas

- Android Studio
- Kotlin
- Jetpack Compose
- Material Design 3
- Git
- GitHub

## Características principales

- Desarrollo de una aplicación móvil nativa para Android.
- Uso de Kotlin como lenguaje principal.
- Creación de interfaces modernas con Jetpack Compose.
- Aplicación de conceptos de Programación Orientada a Objetos.
- Navegación entre diferentes pantallas de la aplicación.
- Organización del proyecto mediante ramas en Git.
- Registro del avance del proyecto mediante commits estructurados.
